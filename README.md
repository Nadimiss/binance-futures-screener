# Binance Futures Screener

Адаптивный веб-скринер USDT-перпетуальных фьючерсов Binance. Использует только публичные рыночные данные Binance — API-ключ не нужен.

## Запуск

Требуется Python 3.9+; сторонние библиотеки не нужны.

```bash
python app.py
```

Откройте в браузере `http://localhost:8000`. Чтобы слушать другой порт, задайте переменную окружения `PORT`, например `PORT=8080 python app.py`.

## Что уже есть

- Ручной поиск и добавление монет из списка торгуемых USDT perpetual Binance.
- Список монет хранится в `localStorage` браузера; до 20 инструментов.
- Адаптивная верстка для смартфона и компьютера.
- Обновление данных примерно каждые 30 секунд.
- Цена, изменения за 5 минут / 1 час / 4 часа / 24 часа, суточный объём.
- Funding, открытый интерес и его изменение примерно за час.
- Проверки направления на основе 4-часового тренда, EMA20 за час, VWAP за 15 минут, объёма и OI.
- Предварительные LONG / SHORT / WAIT оценки, ATR-ориентиры стопа и цели.

## Публикация в интернете (Render)

В проект добавлены `Dockerfile` и `render.yaml` для развертывания как веб-сервиса.

1. Загрузите `app.py`, `index.html`, `Dockerfile` и `render.yaml` в новый репозиторий GitHub.
2. В Render создайте **Blueprint** и подключите этот репозиторий (либо создайте Web Service с Docker runtime).
3. После успешного deploy откройте выданный Render URL на телефоне. Публичная ссылка появится только после того, как сервис будет развернут в вашем аккаунте.

Бесплатный сервис может засыпать при простое; первый запуск после паузы иногда занимает время.

## Примечания

- Данные и метрики поступают с Binance USDⓈ-M Futures API. Доступность API зависит от сети и региона; если Binance блокирует запросы, приложение покажет ошибку API.
- Сигнал — простая техническая оценка, не финансовая рекомендация. Стоп/цель — расчётные ориентиры по ATR, не реальные заявки биржи.
- Для длительной эксплуатации стоит добавить серверный кэш/лимит запросов, журналирование и при необходимости уведомления. Не размещайте приватные API-ключи в браузере.
